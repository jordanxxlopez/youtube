# Character continuity

Teo's approved design is locked. For any task involving Teo's appearance,
illustration, image generation, modeling, animation, prompts, or character
documentation:

1. Read `characters/teo/CHARACTER_LOCK.md` and
   `characters/teo/AGENTS.md` before starting.
2. Visually inspect both approved references in `characters/teo/images/` and
   use the relevant reference as an actual image input for new depictions.
3. Preserve the exact approved face, hair, apparent age, skin tone, physique,
   proportions, clothing, palette, accessories, and visual style. These images
   supersede earlier Teo designs and descriptions.
4. Never overwrite or alter the approved PNG masters. Save derivatives to new
   paths. A new scene or pose does not authorize a character redesign.
5. Obtain explicit user approval before changing Teo's canonical design.

The user explicitly permits natural expression, fluid walking/body motion,
and mouth movement synchronized to spoken dialogue and its prosody. The
character lock preserves appearance; it does not freeze acting or the mouth.

The reference images are authoritative when prose or prompts disagree. This
is a project continuity rule; it does not imply a technical file lock or that
fresh image generation can produce pixel-identical copies.
